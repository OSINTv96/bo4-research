# HMH research · release candidate

Prepared October 19, 2026. Final package review and publication are pending.

- 1,580 recovered code modules: 289 GSC, 88 CSC and 1,203 Lua.
- Two recovered configuration tables and one project-authored native model.
- Source/dependency maps, complete module explanations, original/output fingerprints and offline checks.
- Clean public documentation and anonymous references to undistributed evidence.
- A complete release manifest, privacy checks and deterministic ZIP packaging.

The source collection is unchanged by release preparation. This candidate carries three verified written static proof scopes and four deferred, unproved scopes. It does not establish whole-HMH completion, general decoder/VM equivalence, actual invocation, all effective settings or unavailable online-service behavior. [Current limits](docs/known-gaps.md) separate these findings from earlier evidence.

The game executables, raw captures, assets, screenshots and private research records are excluded. Public credits remain. Original-game redistribution permission and a license for original project work are unresolved; see [license scope](LICENSE-SCOPE.md).

For a fresh copy, follow [getting started](docs/getting-started.md) and run the repository checks, release checks and tests. Later discoveries should identify the exact changed evidence and update the bounded conclusions without converting unknowns into passes.
