# Source configuration and setting reads

The exact recovered [HMH table](../src/config/tables/gametype/gametypetable_wz/warzone_heavy_metal_heroes.json)
has uniqueID804; the [Heavy Metal comparison table](../src/config/tables/gametype/gametypetable_wz/warzone_heavy_metal.json)
has uniqueID778. Both name `warzone` as their base game type. Each has 18 top-level
fields and 35 bundle fields. Unknown hash names remain unchanged. These are
recovered source tables, not a complete effective PS4 settings dump.

The [setting-read inventory](../provenance/settings-read-sites.json) records773
textual sites and 352 distinct named settings across the included source modules.
This includes conditional and other-mode context. It is a navigation index, not
a claim that all 352 settings are active in HMH. Runtime overrides, native getter
types, hash-only settings, assets and current values remain separate evidence.

The saved Part1 screen shows a bounded HMH gate value1 and phase1 before deployment.
It does not prove every setting, exact capture timing or gameplay behavior.

The regenerated text scan also includes seven mixed-case read sites omitted by the historical case-restricted scan. Exact key spelling is retained; the old report stays unchanged.

The original collection recorded 722 sites and 332 names. Those are historical counts; the current collection has 773 textual sites and 352 distinct names.
