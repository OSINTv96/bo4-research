# Build identity

The separate research archive records a PS4 target with title ID **CUSA11100**.
Its observed SFO fields include **VERSION 01.26** and **APP_VER 01.00**. These are
different fields; do not collapse them into an invented single version label.

This repository includes recovered scripts and Lua. It does not ship the executable,
captures, memory dumps, binary assets or console configuration. A version label alone cannot establish
that recovered source matches a game build.

For each later supported claim, record:

- Title/platform and every relevant version field.
- Exact source revision, source path and SHA-256.
- Original or observed byte identity, with known modifications described separately.
- Recovery tool version and any decoder limits.
- The exact comparison performed and the bounds of its result.

Do not reuse an address or VM interpretation across builds without evidence.
